# Правила работы с репозиторием

## Бамп версии перед коммитом

Для каждого набора изменений в коде, который отправляется в `develop`, включая исправления только на сервере, подними patch-версию до первого коммита. Если у этого набора уже есть бамп в текущем PR, используй его для последующих правок.

1. Сверь `APP_VERSION` и `ANDROID_VERSION_CODE` с актуальной `origin/develop`.
2. Запусти `python scripts/bump_version.py X.Y.Z` с новой версией. Скрипт синхронизирует версии сервера и Android, заголовки исходников и ссылку на бета-APK.
3. Вручную увеличь `ANDROID_VERSION_CODE` на 1 в `android-client/gradle.properties` и добавь верхнюю запись RU и EN в `CHANGELOG.md`.
4. Перед коммитом и пушем запусти `python scripts/bump_version.py --check`, проверь код сборки Android и включи все файлы бампа в PR.
